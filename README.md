# Portfólio de Análise de Dados & BI

Bem-vindo(a)! Este repositório reúne meus projetos práticos aplicando **Python, SQL, Power BI e Pesquisa de Mercado** focados em Inteligência de Negócios e Marketing Orientado a Dados.

---

## Tecnologias e Ferramentas
- **Linguagens:** Python (Pandas), SQL (MySQL)
- **Visualização:** Microsoft Power BI
- **Conceitos:** ETL, Data Cleaning, Data Storytelling, Métricas de Vendas e Marketing

---

## Projetos em Destaque

### 1. Dashboard de Vendas - Indústria de Games (Power BI)
- **Objetivo:** Analisar a evolução histórica (1980–2016) e a distribuição geográfica de vendas de jogos.
- **Destaques:** Visão de KPIs principais, segmentação por gênero/região e comportamento de consumo no mercado de NA.
- **Arquivos:** `02-dashboard-powerbi/`

### 2. Treatment & ETL de Base de Marketing (Python)
- **Objetivo:** Automatizar a rotina de higienização de base de dados bruta (`marketing_campaign.csv`).
- **Destaques:** Tratamento de valores nulos, padronização de strings (`strip`/`title`) e remoção de duplicatas por ID.
- **Arquivos:** `01-higienizacao-python/`

### 3. Modelagem Relacional & Consultas Varejo (MySQL)
- **Objetivo:** Estruturação de banco de dados relacional para controle de produtos e vendas.
- **Destaques:** Criação de schemas, relacionamentos entre tabelas e consultas com agrupamentos (`GROUP BY`) e junções (`JOIN`).
- **Arquivos:** `03-banco-de-dados-sql/`
